# 原神祈愿模拟器

面向原神角色活动祈愿的非官方模拟与资源规划工具，支持单抽、十连、保底状态设置、单个或多个 UP 目标预测、自定义卡池与存档管理。

**[在线使用](https://ys.joshzhangzzx.top/)** · [问题反馈](https://github.com/JoshZ-zzx/GenshinWishSimulator/issues) · [ToolBox 旧版存档迁移](https://joshzhangzzx.top/GenshinMigration.html)

## 主要功能

| 功能 | 说明 |
| --- | --- |
| 祈愿模拟 | 单抽、十连、大小保底、捕获明光与累计统计 |
| 单 UP 资源预测 | 根据当前保底、资源与星辉星尘返还估算获得一个 UP 五星的概率 |
| 多 UP 目标规划 | 按额外 UP 数量估算预算内成功率、50%／90%／95% 所需抽数及预算缺口 |
| 自定义卡池 | 五星 UP、四星 UP、池内范围、角色、武器与元素设置 |
| 存档管理 | 导入导出已持久保存的保底状态、累计统计、角色与武器列表及卡池设置 |
| 图片展示 | 内置角色、武器与元素图片，缺失素材时显示名称与占位符 |

## 祈愿与设置

常规祈愿支持单抽和十连，展示抽取结果、保底水位与累计统计。抽取结果支持查看对应的机制说明。

右上角设置按“当期 UP”“保底与统计”“池内范围”“角色与武器”“存档与迁移”分类。分类切换保留尚未保存的输入，“保存全部配置”统一生效；存档导入导出以已保存的数据为准。

默认卡池为项目预设，不会自动同步游戏中的当前卡池。自定义角色没有对应图片时，仍以名称和占位符展示。

## 资源规划

### 单个 UP

单 UP 预测综合起始保底状态、纠缠之缘、原石、星辉、星尘与当月剩余兑换次数，进行多轮独立模拟。每轮从相同状态开始，直到获得一个目标 UP 五星或可用资源耗尽。

星辉和星尘返还按所选估算档位参与资源回收。结果包含成功率、成功轮次的抽数统计与分布，并支持导出逐轮预测 CSV。成功轮次的平均抽数不包含未获得目标的轮次。

### 多个 UP

多目标规划用于同一角色的命座目标或依次抽取多个角色，目标数量最多为额外 14 个 UP。例如额外获得一个 UP 填 1，从未持有到满命填 7。

两个预测模式共用顶部的起始祈愿状态；多目标规划采用其中的五星垫抽数、大小保底与连续歪次数。结果展示预算内成功率、抽数分位点、原石等值、预算缺口、初始状态与抽样误差，计算过程中支持取消。

多目标规划按角色活动祈愿之间保底连续继承计算，不包含跨卡池类型、武器定轨、未来收入或星辉星尘资源回收；资源回收预测由单 UP 模式提供。

## 存档与数据保存

祈愿状态、累计统计、设置和自定义列表保存在当前浏览器，不读取或同步真实游戏账号，也不自动跨设备、浏览器或域名同步。清理浏览器数据可能删除本地存档。

“存档与迁移”支持完整持久存档的 JSON 导入导出。导入会替换当前站点存档，导入前自动在本地保留一份旧存档；这份本地副本不等同于已下载的备份。预测结果 CSV 用于分析，不能作为恢复存档。

### ToolBox 旧版记录

[旧版存档迁移页](https://joshzhangzzx.top/GenshinMigration.html)读取同一浏览器、同一旧域名中的存档，分别导出普通 v2 和图片版 JSON。两种旧版存档相互独立，导出的文件可在独立版“存档与迁移”中导入。

迁移范围仅包含旧版实际持久保存的配置、状态与累计统计，不包含旧版未持久保存的逐抽历史。不同域名之间不能直接读取彼此的浏览器本地记录。

## 使用环境

本工具通过浏览器在线使用，无需安装应用。多目标预测在后台线程中计算，页面需要通过 HTTP 或 HTTPS 访问；直接双击 HTML 文件不支持完整功能。

角色、武器与元素图片由本站加载，无外部图片源兜底请求。图片按需加载，缺失或损坏时保留名称与占位符。

## 概率模型

本项目为非官方工具，概率模型沿用 [ToolBox](https://github.com/JoshZ-zzx/ToolBox) 源码中的规则。逐抽软保底曲线及捕获明光的部分行为采用原工具的拟合假设，不声明为游戏服务器的精确实现。

结果用于概率体验与资源规划，不预测真实账号的祈愿结果。统计结果存在随机抽样波动，也受输入状态、资源与模型假设影响。
